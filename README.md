# Quizora 🧠

> An AI-powered learning app that turns any topic into a custom lesson — notes, a summary, and a quiz — generated for you in seconds.

Quizora started as a simple quiz app and has grown into a full-stack learning tool. Pick a topic, and Quizora builds a lesson around it so you can learn and test yourself in one place.

**🔗 [Live Demo](https://quizora-tammy.netlify.app)**

---

## ✨ Features

- **📊 Dashboard** — See your boards and activity at a glance, with automated updates from the backend. Notifications are in active development.
- **🔍 Explore** — Browse lessons and quizzes created by the community. Sign-in required, so content stays tied to real accounts.
- **👷 Create** — Generate a full lesson on any topic of your choice, complete with notes, a summary, and a quiz to test what you've learned.

## 🚀 Getting Started

Clone the repo and install dependencies for both the frontend and backend:

```bash
git clone https://github.com/Tammyboy23/Quizora.git
cd Quizora

# Frontend
cd Frontend
npm install
npm run dev

# Backend
cd ../backend
npm install
npm start
```

You'll need a Firebase project set up for authentication — add your config to the appropriate `.env` file in the frontend before running.
